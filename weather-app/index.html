API Key Configuration

SkyCast connects to OpenWeatherMap to pull real-time weather and forecasts. You can enter your API key below or edit js/config.js directly.

Why did I see "Invalid or unauthorized API key"?

  1. Activation Delay: Newly registered free OpenWeatherMap keys take 10 to 30 minutes (up to 2 hours) to activate across OpenWeatherMap's servers.
  2. Email Verification: Ensure you confirmed your email address via the link sent by OpenWeatherMap.
  3. Instant Free Live Mode: While waiting for your key to activate, SkyCast automatically uses the public weather API (Open-Meteo) so you can search any city with live real-time data immediately!

🔒 Security note: Client-side API keys are visible in browser developer tools. Never use paid or private backend keys in client-side applications.
